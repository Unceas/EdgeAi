1. Executive Summary & Milestone Context

The Semester VII Engineering Clinics curriculum requires the execution of an evidence-based biomechatronics engineering project. Conventional upper-limb myoelectric prostheses suffer from severe operational limitations: they operate in an open-loop manner, relying on user co-contraction without tactile feedback, which leads to frequent payload slippage or accidental object crushing. Concurrently, deep learning research models demand excessive computing power and memory storage, preventing on-socket embedded execution.

Our project addresses this dual problem by engineering an Edge AI Smart Prosthetic Hand that decouples intention recognition from autonomous tactile force regulation. As of the midterm review milestone, the team has successfully completed the mathematical formulation, algorithmic implementation, backend REST service architecture, automated regression testing suite, and an interactive High-DPI virtual dashboard.

2. Literature Survey & Benchmark Findings

During the initial phase, the team surveyed 35 peer-reviewed publications across five domains: myoelectric control, TinyML edge computing, tactile sensing, NinaPro/putEMG benchmark datasets, and anthropomorphic robotic hand design. Key findings include:

  • Time-Domain Efficiency: Foundational research by Phinyomark et al. (2012) and Hudgins et al. (1993) proves that time-domain features (RMS, MAV, VAR, SSI, ZCR) yield high clustering separability without the computational overhead of Fast Fourier Transforms.
  • Tree Ensembles for Edge AI: Constrained Random Forest models (Breiman, 2001) offer non-linear multi-class decision boundaries while occupying less than 200 KB storage, making them vastly superior to deep neural networks for embedded microcontrollers.
  • Slip Compensation Latency: Research by Kyberd (2023) and Liu et al. (2015) indicates that autonomous slip correction must occur within 20 milliseconds directly at the actuator tier to prevent object drops.

5. Encountered Technical Bottlenecks & Audit Fixes

Prior to the midterm milestone, an exhaustive read-only code audit was conducted. Several critical stability and integrity issues were identified and successfully resolved:

  1. Zero-Crossing Rate Division-by-Zero Vulnerability: In the original code, `zcr = crossings / (N - 1)`. When empty buffers (\(N=0\)) or single-sample buffers (\(N=1\)) were supplied, the denominator caused an unhandled `ZeroDivisionError`. The function was redesigned with guard conditions: `if n < 2: return 0.0`. TC-05 and TC-06 now verify this edge condition.
  2. Input Validation & HTTP 500 Prevention: Malformed client requests previously crashed the FastAPI worker, returning HTTP 500 Internal Server Errors. We implemented strict Pydantic model validators with boundary checks, returning standardized HTTP 422 Unprocessable Entity responses.
  3. Resting Noise Parameter Connection: The baseline noise calibration parameter was previously ignored during signal synthesis. The generator now incorporates `baseline_noise` directly into the Gaussian noise generation function (`std=baseline_noise`).
  4. Real Host CPU Latency Profiling: Previously, the API returned a hardcoded latency constant (1.46 ms). This was replaced with dynamic profiling using `time.perf_counter_ns()`, measuring actual execution times across 50 warmed-up trials.
  5. High-DPI Canvas Resizing: The sEMG canvas previously exhibited blurriness on Retina screens. We implemented device pixel ratio (`window.devicePixelRatio`) auto-scaling to ensure sharp, responsive rendering.
  6. Controller Progression State Completeness: The grip controller lacked a `DECREASING` state when force exceeded the upper deadband setpoint. This was added to ensure complete state coverage.

7. Closed-Loop Tactile Control Verification

The closed-loop force regulation dynamics were verified across five operating states:

  1. Free Travel Closing: Actuator displacement advances by \(+3.5\text{ mm/cycle}\) while contact force remains nominal (< 5.0 N).
  2. Contact Threshold Detection: At \(F_n = 5.0\text{ N}\), the controller detects object touch and transitions from `CLOSING` to `CONTACT_DETECTED`.
  3. Proportional Tracking & Deadband: Force steps upward at \(+1.5\text{ N/cycle}\) until entering the \([47.0, 53.0]\text{ N}\) deadband window, transitioning to `STABLE_HOLD` at 49.8 N.
  4. Autonomous Anti-Slip Reflex: Upon asserting `slip_detected = True`, the controller executes an immediate +18% force boost (+12.0 N), arresting payload slippage in one cycle (20 ms).
  5. Anti-Crush Safety Ceiling: Forced over-pressure is clamped strictly to 75.0 N, triggering `CRUSH_ABORT`.
